# Generated previews

Run `python render_book.py` from the project root to produce `001_specimen.svg`, `001_story.svg`, individual preview PNGs, and `001_spread_preview.png`.

Run `python render_book.py --text-mode editable` for `generated/editable/`.

SVG illustration and raster lettering layers link to images under `../assets/`. Binary files are being uploaded separately.
