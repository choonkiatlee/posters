# Posters

Illustrations, posters and print projects, organised into independent subprojects.

## Projects

### [《小巨蛋世界試吃計畫》 — Little Egg's World Tasting Project](projects/xiao-judan-world-tasting/)

Traditional Chinese children's picture book, illustrated in textured gouache.

The project includes a YAML manuscript, reusable design settings, an original-lettering and editable-text SVG renderer, and generators for portrait PNG and two-page spread previews.

**Asset status:** Source and configuration files are being committed first. Binary illustration and reference PNGs are preserved in the prepared project archive and still need to be uploaded. Until then, image rendering and preview checks cannot run successfully.

More projects can be added as siblings inside `projects/`.
